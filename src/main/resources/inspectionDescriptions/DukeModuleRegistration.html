Reports a ModuleFactory.register(...) call whose name is not the simple name of the module class it builds.

INI files name a module by what it was registered under. Keeping that the class name means an INI line can be read, completed and checked against the class itself.

Example:

factory.register("mover", (owner, data) -> new MoveUpdate(owner, (MoveUpdate.Data) data), MoveUpdate::parseData);

The quick fix registers the module as "MoveUpdate" and renames the INI lines that used mover.

Modules registered once per name under a TAG_PREFIX, such as ScriptModule, are not reported.
